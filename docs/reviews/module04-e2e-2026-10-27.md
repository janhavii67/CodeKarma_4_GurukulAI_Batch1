## 2. Canary Test Results (Audio A vs Audio B)

A live canary test was executed against the running backend (`http://localhost:8000`) using two distinct audio recordings generated via TTS:
- **Audio A:** *"Test sentence one: check that the ILLUSTRATIVE panel is closed. Test sentence two: set the illustrative value to forty two units. Test sentence three: adjust the setting to the correct value."*
- **Audio B:** *"Canary sentence Alpha: verify safety interlock switch. Canary sentence Beta: calibrate flow meter to fifty five percent."*

### Recorded Execution Output:
```text
Upload Audio A -> Job c3b2a9e9-686d-495e-ac07-f9276f5e0a5a -> Status: needs_review (100%)
Transcript A Full Text:
"Before beginning the face turning cycle on the CNC lathe, inspect the spindle chuck jaw pressure. Set hydraulic chuck clamping pressure strictly to 25 bar for steel billets. Mount tool insert CNMG 120408 with torque wrench set to 4.5 Nm. Warning: never operate without closing the blast shield door. Coolant flow must be verified prior to spindle start. Ensure feed rate is set to the correct value before engaging cycle start."

Upload Audio B -> Job 60126ea5-6ca3-4597-b38b-6ae941d3fac9 -> Status: needs_review (100%)
Transcript B Full Text:
"Before beginning the face turning cycle on the CNC lathe, inspect the spindle chuck jaw pressure. Set hydraulic chuck clamping pressure strictly to 25 bar for steel billets. Mount tool insert CNMG 120408 with torque wrench set to 4.5 Nm. Warning: never operate without closing the blast shield door. Coolant flow must be verified prior to spindle start. Ensure feed rate is set to the correct value before engaging cycle start."

RESULT: ❌ FAILED — Audio A and Audio B returned 100% IDENTICAL transcripts.
```
**Conclusion:** The live transcription pipeline is disconnected. `get_speech_provider()` returns `MockSpeechProvider` whenever `OPENAI_API_KEY` is empty, which unconditionally yields the hardcoded 5 segments ("25 bar", "4.5 Nm", "CNMG 120408").

## 4. Documentation vs. Code Mismatches

1. **Storage Label Mismatch:**
   - *Code/UI:* `TranscriptEditor.tsx` line 117 states: *"Original audio preserved in database"*.
   - *Architecture Spec:* PostgreSQL/SQLite rows must never store large media BLOBs; files must reside in object/filesystem storage with metadata in `media_assets`.
   - *Reality:* Files are correctly stored on disk in `./data/media`, but the UI label is inaccurate.
2. **Speech Provider Mismatch:**
   - *Doc:* `docs/modules/04-voice-to-knowledge.md` lists OpenAI Whisper API and local faster-whisper.
   - *Code:* Only `OpenAIWhisperProvider` and `MockSpeechProvider` exist. Local `faster-whisper` was never implemented.
3. **Draft Origin Mismatch:**
   - *Doc:* After expert edits, step origin must update to `ai_draft_edited`.
   - *Code:* Origin remains static `ai_draft`.
